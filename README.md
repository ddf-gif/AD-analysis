## 每篇包含什么

每篇拆解采用统一结构,便于横向对比:

1. **定位** — 它到底是什么?用「不是 A,而是 B」定义
2. **人群** — 谁在用?被什么场景「淘汰」出来的?分几种角色?
3. **场景** — 什么时候用?时间 × 情绪 × 社交能量
4. **需求** — 表层 / 中层 / 深层,本质是哪一句话?
5. **机制** — 每道「减法」减掉了什么成本?
6. **商业** — 收入结构、单位经济、核心悖论
7. **增长** — 获客引擎、留存引擎、流失结构
8. **判断** — 三个反直觉的结论
9. **风险** — 最可能死在哪?
