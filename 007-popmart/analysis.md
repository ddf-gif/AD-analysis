# 泡泡玛特:把「惊喜」做成一条流水线

> 拆解对象:泡泡玛特(POP MART,HK:09992)
> 数据基准:2026 年中期财报(截至 2026.6.30)+ 2026 年 Q3 公开数据
> 拆解维度:定位 → 模式 → IP 矩阵 → 人群 → 场景 → 需求 → 周期 → 判断与风险

---

## 一、先给结论

如果只用一句话概括泡泡玛特:

> **它卖的从来不是「玩具」,它卖的是「情绪价值的盲盒化」——把「惊喜」做成一条可复制的工业流水线。**

这句话拆开是三层:

1. **惊喜是产品**:你买的不是那只玩偶,是「拆开之前的那 3 秒」;
2. **IP 是资产**:MOLLY、LABUBU、星星人——每一个都是一个「情绪容器」;
3. **盲盒是发行方式**:不确定 + 稀缺 + 系列,让「收集」变成「上瘾」。

**泡泡玛特真正的商业模式,不是「卖潮玩」,而是「用盲盒发行 IP」。**

这也是为什么它能做到 69.7% 的毛利率——**它卖的不是塑料,是概率。**

## 二、它是什么:一家「IP 经纪公司」

### 2.1 三个身份

| 身份 | 做什么 | 类比 |
|---|---|---|
| **IP 经纪** | 签约设计师、孵化 IP、运营 IP | 经纪公司 |

| **渠道商** | 门店、机器人商店、电商 | 零售连锁 |

**它更像「迪士尼 + 游戏公司 + 零售连锁」的混合体。**

### 2.2 从「杂货铺」到「IP 公司」

**它用 15 年,走完了「代理商 → 品牌商 → IP 公司」的三级跳。**

## 三、模式:盲盒的三层设计

### 3.1 不确定性:最便宜的「赌」

- 一个盲盒 59-99 元,你不知道里面是什么;
- 抽到普通款,「还行」;抽到隐藏款,「赚了」;
- 这种「小额赌博」,和抽卡、开蛋、扭蛋是同一个心理机制。

**盲盒的本质,是「用小额赌注,买一次情绪波动」。**

### 3.2 稀缺性:隐藏款与限定款

- 隐藏款概率 1/144 甚至更低;
- 限定款只在线下、只在某个城市、只卖几天;
- 二手市场的「溢价」,反过来强化了「抽到就赚」的预期。

**稀缺不是「产量少」,是「让你觉得可能抽不到」。**

### 3.3 系列化:让「一个」变成「一套」

- 每个 IP 每季出一套(12 个常规 + 1 个隐藏);
- 你抽到一个,就想凑齐一套;
- 凑齐一套,又想等下一季。

**系列化,把「一次性消费」变成了「长期订阅」。**

### 3.4 一台「情绪印钞机」

| 指标 | 数值 | 含义 |
|---|---|---|
| 毛利率 | 69.7% | 接近游戏、化妆品 |
| 经调整净利率 | 30% | 远高于普通零售 |
| 会员复购率 | 51.6% | 一半会员会再买 |
| 会员贡献销售 | 92.9% | 生意靠「老客」 |

**这不是零售的利润率,这是「内容 + 概率」的利润率。**

## 四、IP 矩阵:一条「IP 流水线」

### 4.1 2026 上半年 IP 收入

| IP | 收入 | 同比 | 占比 |
|---|---|---|---|
| **THE MONSTERS(LABUBU)** | 44.5 亿 | **-7.5%** | 26% |
| **星星人** | 26.5 亿 | **+580.6%** | 15% |
| CRYBABY | 16.3 亿 | +34% | 9.5% |
| DIMOO | 16.2 亿 | +46.5% | 9.4% |
| SKULLPANDA | 15.5 亿 | +27.1% | 9% |
| Hirono 小野 | 10.1 亿 | +38.5% | 5.9% |
| MOLLY | 9.0 亿 | — | 5.2% |
| 毛绒品类(合计) | 98.2 亿 | +60% | — |

### 4.2 一个关键转折:LABUBU 首次下滑

- THE MONSTERS 收入 44.5 亿,同比 **-7.5%**;
- 占比从去年同期的 34.7%,降到 26%;
- 2026 年 6 月「复古理发店」系列,**多款跌破发行价**(破发);
- 这是 LABUBU 成为超级 IP 以来,第一次收入同比下滑。

**同时,星星人接棒:26.5 亿,+580.6%,跃居第二。**

### 4.3 这说明什么

**第一,超级 IP 有周期。**

LABUBU 的爆发,靠的是「全球性的审美巧合 + 名人带货 + 社交媒体」;它的退潮,也是同样的原因——**热度是被制造的,也会被消耗。**

**第二,IP 矩阵是「抗周期」的唯一办法。**

如果只有 LABUBU,2026 年就是灾难;但星星人、CRYBABY、DIMOO 接住了缺口。

**第三,IP 流水线是可以复制的。**

MOLLY(2016)、LABUBU(2019)、星星人(2024)——每隔几年,就有一个新 IP 跑出来。

**泡泡玛特真正的能力,不是「拥有 LABUBU」,是「能造出下一个 LABUBU」。**

- 新加坡圣淘沙 POP BAKERY:一楼零售 + 二楼烘焙(40 座);

**这不是「开一家店」,是「输出一个业态」。**

## 七、需求:四层,本质是「情绪定价」

```
第四层  社交需求    「我有,你没有」
   ↑
第三层  收集需求    「我要凑齐一套」
   ↑
第二层  惊喜需求    「拆开的那 3 秒」
   ↑
第一层  审美需求    「它好看 / 它可爱」
```

**第一层:审美。** 好看、可爱、有设计感——这是入场券。

**第二层:惊喜。** 拆盒的 3 秒,是多巴胺的高峰。

**第三层:收集。** 凑齐一套、抽到隐藏,是「完成感」。

**第四层:社交。** 晒娃、换娃、开箱视频——「我有,你没有」是身份。

**本质一句话:**

> **用户买的不是「玩偶」,是「一次确定的开心」和「一次不确定的惊喜」。**

**泡泡玛特的定价,不是按「成本」,是按「情绪」。**

一个 59 元的盲盒,成本可能不到 20 元;剩下的 40 元,是「惊喜的设计费」。

| 海外亚马逊 | — | **-60%~-88%** |
| LABUBU 搜索热度 | — | 环比 **+39%** |

**注意最后一行的反差:销售在跌,搜索在涨。**

这说明:**LABUBU 不是「没人要了」,是「该买的人都买了」。**

### 8.2 三个信号

**信号一:增收不增利。**

2026 H1,营收 +23.8%,净利只 +10.1%;净利率从 33.9% 降到 30%。

**信号二:预期差。**

市场预期营收 199.8 亿、净利 66.4 亿,实际 171.7 亿、50.38 亿——差了 28 亿和 16 亿。

**信号三:股价。**

从历史高点 337 港元,跌到 153 港元附近,缩水五成。

### 8.3 管理层的应对

- 把 2026 年定义为「**休整年**」;
- 王宁:重心不在销售高速增长;
- 启动 **20-50 亿港元回购**;
- 加速多 IP 矩阵、多业态、出海。

**这是一次「主动降速」,也是一次「被动调整」。**

## 九、六个判断

### 判断一:盲盒是「发行方式」,不是「产品」

- 产品是 IP,盲盒是「怎么卖」;
- 同样的 IP,可以盲盒、可以毛绒、可以珠宝、可以乐园;
- **泡泡玛特的核心能力,是「IP 的发行能力」。**

### 判断二:它的护城河是「IP 运营」,不是「IP 本身」

- IP 会过气(LABUBU 已经证明了);
- 但「造 IP、养 IP、换 IP」的能力,可以持续;
- **它真正的资产,是那条「IP 流水线」。**

### 判断三:潮玩的本质是「时尚」,时尚有周期

- 潮玩不是「必需品」,是「情绪消费品」;
- 情绪消费,天然有「新鲜感」的折旧;
- **LABUBU 的退潮,不是失败,是规律。**

### 判断四:出海是「业态输出」,不是「商品输出」

- 卖货,靠的是「渠道」;
- 卖业态,靠的是「品牌 + 体验」;
- **POP BAKERY 出海,比「多开 10 家店」更有价值。**

### 判断五:它的天花板,不是「潮玩」,是「IP 的边界」

- 潮玩市场规模有限;
- 但 IP 可以做乐园、做电影、做游戏、做珠宝;
- **它真正的对手,是迪士尼、是三丽鸥、是万代。**

### 判断六:2026 是「成人礼」,不是「衰退」

- 从「单品爆发」到「矩阵运营」;
- 从「中国品牌」到「全球品牌」;
- **能穿过周期的公司,才配叫「IP 公司」。**
