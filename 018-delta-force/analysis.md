# 三角洲行动:把「硬核射击」做成国民级消费品

> 调研对象:腾讯天美 J3(琳琅天上)《三角洲行动》(Delta Force)
> 调研维度:时间线 · 定位 · 人群 · 场景 · 需求 · 机制 · 商业模式 · 竞争 · 风险 · 判断
> 一句话:**它不是「更硬的 FPS」,而是把 FPS 的入场费打到零——用「免费 + 三端 + 双模式 + 输了不归零」,把塔科夫式的冒险,做成了 5800 万人每天开一局的「风险平价赌局」。**

---

## 一、结论先行:它到底赢在哪

先给三个反直觉的结论:

1. **它赢在「减法」,不在「加法」。** 论硬核,它不如《逃离塔科夫》;论枪感,它不如 CS;论战场规模,它不如《战地》。但它把这三件事的门槛一起拆了。
2. **5800 万 DAU 是「流量资产」,不是「收入资产」。** 以第三方移动口径计,它 2025 年累计收入约 5 亿美元,约为《王者荣耀》**单年**收入的四分之一。
3. **它最怕的不是竞品,是「被算法安排」的感觉。** 黑屋局、爆率、赛季削弱——这些运营手段在保留存,也在透支「这局是我自己打出来的」的信任。

### 五维完成度评分

| 维度 | 分数 | 判断 |
|---|---|---|
| 玩法 | 9/10 | 「搜打撤 + 大战场」双模式,一个入口覆盖两种时间颗粒 |
| 技术 | 8/10 | PC/移动/主机三端互通,UE5 规格战场地图 |
| 运营 | 8/10 | 26 个月跑到 S12 赛季,平均约 2 个月一更 |

| **综合** | **7.5/10** | **国民级产品已成立,「长青」还没被验证** |

> 一句话:**它把「硬核玩法」做成了「大众消费品」——代价是,消费品的生命周期由「内容产能」而不是「玩法深度」决定。**

## 三、定位:三层拆开看

### 产品层:不是「塔科夫平替」,是「一鱼两吃」

- **烽火地带**:20 分钟一局,带装备进图、搜物资、打人机/打人、撤离带走——**赌注型**玩法;
- **全面战场**:32v32 载具大战场,死了就复活,拼的是点位与火力——**爽局型**玩法;
- 两个模式共用干员、枪械、改装、仓库——**一份资产,两种消费场景**。

> 这是它和塔科夫最根本的区别:**塔科夫只有「赌」,三角洲还有「爽」。**

### 价格层:不是「买断制硬核」,是「零元入场」

| 产品 | 入场价 | 变现 |
|---|---|---|
| 《逃离塔科夫》 | 约 40-50 美元买断 | 买断 + 版本升级 |
| 《ARC Raiders》 | 约 40 美元买断 | 买断 |
| **《三角洲行动》** | **0 元** | 外观 / 通行证 / 安全箱 |
| 《和平精英》 | 0 元 | 外观 / 通行证 |

**它把「硬核」从「门票制」改成了「商场制」。** 结果是:用户规模上一个量级,单用户收入下一个量级。

### 心智层:不是「更真实的战争」,是「可承受的冒险」

- 死了有**保险**,装备能找回一部分;
- 输了有**制式装备 / 战备补给**,下一局还能进;
- 赢了能**带走**,仓库里的东西是真的;
- 赛季结束**不清档**(区别于塔科夫的删档机制)。

> 一句话:**它卖的不是「硬核」,是「硬核的安全感」。**

## 四、人群:五类人,五种「被淘汰出来」的理由

### 1. 端游老兵(CS / 战地 / COD 迁移)

- 从哪来:CS 的竞技疲劳、战地的外挂、COD 的年货厌倦;
- 要什么:**枪感、公平、不卖数值**;
- 痛点:手游化操作、干员技能「不够纯粹」;
- 规模:核心盘,舆论场最响的一群人。

### 2. 塔科夫「云玩家」

- 从哪来:看过塔科夫视频,被「硬核 + 昂贵 + 高门槛」劝退;
- 要什么:「搜打撤」的紧张感,但**不想被惩罚**;
- 三角洲给他们的:保险、安全箱、跑刀、保底装备;
- **这是它最大的一块增量。**

### 3. 手游泛射击用户(和平精英溢出)

- 从哪来:和平精英玩了五六年,想要「新东西」;
- 要什么:熟悉的手感 + 新鲜的玩法 + 更「成年」的审美;
- 三角洲给他们的:双端互通,手机也能玩「摸金」。

### 4. 学生 / 年轻上班族

- 时间:一局 15-25 分钟,午休、通勤、睡前都能开;
- 要什么:**碎片时间里的高浓度刺激**;
- 付费:通行证 48 元 / 68 元,是「月卡级」心理价位。

### 5. 内容生产者(主播 / 陪玩 / 搬砖 / 护航)

- 靠「出货叙事」吃饭:一发入魂、红皮、绝密局;
- 副作用:**护航、代练、卖金**的灰色产业链;
- 他们是 DAU 的一部分,也是舆论风险的一部分。

> 五类人有一个共同点:**他们都不是「硬核玩家」,而是「想要硬核体验的普通人」。**

## 五、场景:八个具体时刻

1. **21:30 下班后**:不想动脑,单排跑刀,「进去摸一圈就撤」;
2. **周末四人开黑**:全员六套猛攻,输了互相骂,赢了截图发群;
3. **地铁通勤**:手机端收菜、清日常、领邮件;
4. **深夜单排**:仓库只剩最后一套,「这一把要么翻本要么归零」;
5. **出红瞬间**:手抖、屏息、找撤离点——**这是产品的情绪峰值**;
6. **赛季初**:通行证冲级、新干员解锁、赛季皮肤;
7. **大战场**:开直升机、抢点、被载具碾——**这是产品的「爽点兜底」**;
8. **赛事周**:DFI 观赛 + Twitch Drops,看 15 分钟领「战备物流凭证」。

> 前四个场景是「日常」,第五个是「传播」,第七个是「留存」,第八个是「生态」。

## 六、需求:五层金字塔

```
        ┌─────────────────────────┐
        │ 5. 本质:可控的冒险      │  ← 一句话
        ├─────────────────────────┤
        │ 4. 社交:开黑/背叛/炫耀  │
        ├─────────────────────────┤
        │ 3. 深层:风险与回报的赌  │
        ├─────────────────────────┤
        │ 2. 中层:收集/成长/改装  │
        ├─────────────────────────┤
        │ 1. 表层:枪感/画面/爽     │
        └─────────────────────────┘
```

- **表层**:开枪的手感、命中的反馈、爆炸的画面;
- **中层**:仓库、干员、枪械改装、赛季通行证——**「攒东西」的确定性**;
- **深层**:带什么进图、走哪条路、什么时候撤——**「赌」的不确定性**;
- **社交层**:开黑、语音、背叛、炫耀——**「人」的变量**;
- **本质**:**用最小的代价,体验一次「可能失去一切」的冒险。**

> 泡泡玛特卖的是「情绪抽奖」,三角洲卖的是「**风险抽奖**」——区别是,前者的赌注是 69 元,后者的赌注是你昨天攒的一仓库。

## 七、机制:六道减法

### ① 价格减法:0 元入场

对比买断制,它把「试错成本」降到零。**用户不需要「决定要不要玩」,只需要「决定要不要充」。**

### ② 设备减法:三端互通

一个账号,PC / 手机 / 主机同进度。**它把「玩什么设备」这个决策,也删掉了。**

### ③ 学习减法:死亡不归零

- 保险:死了能找回部分装备;
- 安全箱:关键物资塞进去,死了不掉;
- 制式装备 / 战备补给:保底能再进一局;
- 跑刀:零成本进图,摸到就是赚。

**塔科夫的痛点是「死一次回到解放前」,三角洲把这条删了。**

### ④ 时间减法:单局 15-25 分钟

大战场 25-30 分钟,烽火地带 15-20 分钟。**适配「打工人时间」,而不是「硬核玩家时间」。**

### ⑤ 失败减法:匹配与「黑屋」

- 新手保护、连败保护、装备匹配;
- 「黑屋」:把高收益/高击杀玩家放进更高强度的对局——**用算法调控「胜率与爆率」**;
- 争议点:玩家感知「被安排」,而不是「被匹配」。

### ⑥ 社交减法:语音 / 公开麦 / 组队大厅

- 大厅组队、语音开黑、公开麦;
- 陪玩、护航、代练由此长出来——**社交降低了门槛,也放大了灰色产业。**

> 六道减法,每一道都在**扩大用户基数**,也都在**稀释「硬核感」**。这是它和核心玩家的永恒拉扯。

## 八、商业模式:一个「反 ARPU」的国民级产品

### 1. 收入结构(按公开信息推断)

| 收入项 | 形态 | 价格带 |
|---|---|---|
| 通行证 | 赛季制,单模式 / 豪华版 | 约 48 元 / 68-72 元 |
| 皮肤 | 直售 + 抽奖(曼德尔砖) | 几十到数百元 |
| 安全箱 | 赛季内 2×3 格扩容 | 通行证内付费解锁 |
| 联名 | 吴彦祖、海底捞等 | 拉新 / 破圈 |
| 赛事 | DFI 2025 杭州、DFI 2026 瑞典 | 品牌投入期 |

### 2. 单位经济(粗算)

```
日流水 ≈ DAU × ARPDAU
       ≈ 5,800 万 × 0.2-0.5 元
       ≈ 1,200 万 - 2,900 万元/日
年流水 ≈ 40 亿 - 100 亿元(含国内安卓/PC,估算)
```

> **估算说明**:ARPDAU 区间参考国内免费射击品类;真实值受赛季、皮肤档期影响,波动很大。此处只用于量级判断,不作为财务依据。

### 3. 两个核心悖论

**悖论一:公平与深度不可兼得。**

- 不卖数值 → 付费天花板低 → 只能靠 DAU 规模;
- 要 DAU → 必须降低门槛 → 硬核玩家流失;
- 硬核玩家流失 → 社区「技术鄙视链」弱化 → 内容传播力下降。

**悖论二:算法调控与「赌局公平」。**

- 黑屋、爆率、赛季削弱,本质是**用算法管理留存曲线**;
- 但「搜打撤」的核心体验是「我赌赢了」;
- 当玩家发现「赢是算法给的」,赌局就变成了**老虎机**——短期留存上升,长期信任下降。

> 一句话:**它用「不卖数值」换来了口碑,又用「算法调控」把口碑一点点抵押出去。**

## 九、营销:把福利做成内容,把赛事做成广告

### 1. 不是「买量」,是「产品即广告」

- 0 元入场 + 三端互通,本身就是最大的获客素材;
- 腾讯自有流量池:微信 / QQ / 应用宝 / 视频号 / 腾讯视频——获客成本结构性低于独立厂商;
- 官网、渠道礼包、加速器合作,把「下载」变成「领福利」。

### 2. 福利型增长:用「送」换「回」

| 节点 | 动作 | 目的 |
|---|---|---|
| 春节 / 开年 | 刘涛送六套顶级装备、捆绑包四选一、免费传说外观 | 拉回流、冲 DAU |
| 二周年 | 全服邮件答谢、限定头像/挂饰/喷漆、吴彦祖联动 | 情绪与话题 |
| 日常 | 口令码在评论区、社群传播 | 零成本裂变 |
| 赛季 | 免费线送新干员 | 保活跃 |

> 福利不是成本,是「注意力采购」——用装备和外观,买玩家的下一次登录。

### 3. 内容营销:卖「出红」的瞬间

- 主播 / 短视频:一发入魂、红皮、绝密局——**把概率事件剪成确定性爽感**;
- 官方:CG、真人短片、版本 PV、开发者访谈;
- 代言:二周年吴彦祖——打「港片 / 硬汉」记忆,对准 25-35 岁男性。

### 4. 破圈联名:把「搜打撤」搬进生活

- 海底捞门店联动,把「搜打撤」的紧张感延伸到线下餐饮;
- 城市灯光秀、春节主题场景;
- 逻辑:游戏内是「撤离」,游戏外是「聚会」——**联名卖的是社交场景,不是皮肤。**

### 5. 赛事营销:DFI 是「广告牌」,不是「生意」

- 2025 杭州首届 → 2026 瑞典 DreamHack,12 支队伍、50 万美元奖金;
- Twitch Drops:看 15 分钟领「战备物流凭证」,把观众变成玩家;
- 游戏内预测:猜中冠军得传奇枪皮,把「看比赛」变成「登录理由」;
- 首个入选 DreamHack 官方竞技项目的中国发行电竞游戏——**买的是「全球品类合法性」。**

### 6. 渠道与私域:把「充值」做成「省钱攻略」

- 官方小程序充值送三角币 + 优惠券;
- 授权店铺(洲洲小铺)单模式通行证约 47 元,比游戏内便宜约 1 元;
- 九游等渠道礼包、口令码;
- 效果:降低「首次付费」的心理门槛,把付费前置到「买通行证」这一步。

### 7. 节奏:赛季就是营销日历

- 平均 2 个月一个赛季 = 一年约 6 次「上新发布会」;
- 版本名(微光 / 群星)+ 新干员 / 新图 / 新玩法 = 天然传播点。

> 一句话:**它的营销不是「投放」,是「把福利、赛事、联名都做成内容」——获客靠腾讯流量池,留存靠赛季,转化靠外观。**

### 8. 营销的三个隐患

- **福利依赖**:玩家被「送」养成,停送即掉 DAU;
- **代言与联名舆情**:艺人风险会直接砸在品牌上;
- **赛事 ROI**:50 万美元奖金 + 全球差旅,短期换不来收入,只能换品牌。

## 十、竞争:腾讯的「全谱系」与「左右互搏」

### 1. 品类大盘:射击已是第一

- 2026 上半年,收入前 100 移动游戏中,**射击类占 26.23%**,首次超过 MOBA(18.96%);
- 客户端游戏实销 **452.88 亿元,同比 +27.92%**——跨端是主要推力;
- 中国射击占大盘约 20%,全球约 35%——**还有一倍空间**。

### 2. 对手矩阵

| 产品 | 定位 | 与三角洲的关系 |
|---|---|---|
| 《和平精英》 | 战术竞技,大 DAU | 同门,分流「吃鸡」用户 |
| 《暗区突围》 | 更硬核的搜打撤 | 同门,承接硬核玩家 |
| 《无畏契约》 | 竞技 FPS | 同门,承接电竞人群 |
| 《ARC Raiders》 | 买断制 PvE 搜打撤 | 全球 1,500 万份、半年近 50 亿元;腾讯代理国服《弧光猎人》 |

## 十一、隐忧:六个可能死掉的地方

| 风险 | 说明 | 量级 |
|---|---|---|
| **内容消耗** | 平均 2 个月一个赛季,地图/干员/玩法迭代压力;同质化后 DAU 见顶 | 高 |

> 最危险的不是「不好玩」,是**「玩家觉得这局不是自己打的」**。

## 十二、六个判断

### 1. 它赢在「减法」,不在「加法」

免费、三端、保险、保底、短对局——**每一步都在拆门槛**。这不是「更硬核的射击」,是「更便宜的冒险」。

### 2. 5,800 万 DAU 是「入口」,不是「收入」

以第三方口径,它一年累计收入约等于《王者荣耀》单年的四分之一。**腾讯买的是「品类王座」,不是「当期利润」。**

### 3. 「搜打撤」的终局是「风险定价」

谁能把「输得起」做到极致,谁就能拿走泛用户。塔科夫卖「真实」,三角洲卖「容错」——**容错,才是大众市场的硬通货**。

### 4. 黑屋机制是「止痛药」,也是「毒药」

短期稳住留存曲线,长期透支「赌局公平」。**当玩家开始研究「怎么不进黑屋」而不是「怎么打好这一局」,产品的魂就换了。**

### 5. 腾讯的「左右互搏」是护城河

和平、暗区、无畏、三角洲、ARC 国服——**它不怕自己打自己,它怕的是别人来打。**

### 6. 真正的对手是「时间」

26 个月 12 个赛季,内容产能决定它能「长青」多久。**射击品类的护城河从来不是玩法,是「持续供给内容的能力」。**
