# 东东电竞:把「陪玩」做成「电竞版海底捞」

> 拆解对象:东东电竞(DONGDONG E-GAME),淮南东东网络科技有限公司
> 创始人:刘旭东;2022 年线下起家,2025 年 7 月 App 公测
> 数据基准:2026 年公开报道(百度百科、应用商店、虎扑、17173 等)
> 拆解维度:定位 → 人群 → 场景 → 需求 → 模式 → 争议 → 判断与风险

---

## 一、先给结论

如果只用一句话概括东东电竞:

> **它卖的不是「陪玩」,是「游戏里的陪伴和面子」——把「一个人打游戏」的孤独,做成了「有人陪你打、有人捧你」的生意。**

这句话拆开是三层:

1. **陪玩是产品**:段位、声音、颜值,都是「可售卖的服务」;
2. **陪伴是内核**:用户买的不是「上分」,是「有人一起」;
3. **被捧是溢价**:一句「老板」,能让客单价翻倍。

**它的定位不是「游戏平台」,是「电竞版海底捞」——卖的是「被服务的感觉」。**

---

## 二、它是什么:从网咖到陪玩平台

### 2.1 一条「反向」的路径

大多数平台是「线上起家,再开线下店」;东东电竞是反的:

| 时间 | 动作 |
|---|---|
| 2022 | 河北定州,第一家线下电竞门店 |
| 2023.6 | 成立淮南东东娱乐文化传媒 |
| 2025.4 | 成立淮南东东网络科技 |
| 2025.7 | App 上线安卓/iOS 公测 |
| 2025.10 | 发布俱乐部招募令,启动全国加盟 |
| 2026 | 月流水破 2 亿,注册用户超 500 万 |

**它先有「线下服务经验」,再做「线上平台」——这决定了它的基因:重服务、重管理、重口碑。**

### 2.2 卖什么

| 业务 | 内容 |
|---|---|
| **陪玩** | 按游戏、段位、价格、性别、在线状态筛选,自助下单 |
| **语音房** | 排位车队、休闲娱乐、连麦唱歌、剧本杀式聊天 |
| **赛事** | 水友赛、挑战赛,赢金币或现金 |
| **社区** | 图文动态、关注大神、话题讨论 |
| **俱乐部** | 俱乐部入驻、加盟、标准化管理 |

**覆盖游戏:《三角洲行动》《永劫无间》《无畏契约》《绝地求生》《英雄联盟》《王者荣耀》。**

### 2.3 一个关键的「管理」设计

东东电竞被称为「电竞界海底捞」,不是因为它「服务好」,是因为它「管得严」:

- 陪玩必须满 18 周岁、实名;
- 考核要「一镜到底」、录第一视角、全程语音;
- 禁止私单、低俗色情、外挂、代打;
- 娱乐考核、技术考核,各 500 钻石/轮;
- 动态考核,成绩只有一个月有效期。

**「严」,本身就是一个卖点:它把「陪玩」从「灰色地带」,往「正规服务」拉了一步。**

## 三、人群:两种人,一个场

### 3.1 老板(下单者)

| 维度 | 画像 |
|---|---|
| 性别 | 男性为主 |
| 年龄 | 25-40 岁 |
| 特征 | 有消费力、孤独、需要陪伴、需要被捧 |
| 动机 | 上分、打发时间、找人聊天、被叫「老板」 |

**「老板」这个词,是理解东东电竞的钥匙。**

在游戏里,他可能是个普通玩家;在这里,他是「老板」——有人等他、有人夸他、有人陪他。

**他买的不是技术,是「被重视」。**

### 3.2 陪玩(服务者)

| 维度 | 画像 |
|---|---|
| 年龄 | 18-30 岁 |
| 特征 | 技术好 / 声音好 / 颜值高 |
| 身份 | 兼职为主,也有全职 |
| 收入 | 订单分成,平台抽成 |

**陪玩是「供给端」,也是「平台最不稳定的部分」:**
- 收入不稳定;
- 管理严格(罚款、考核、封号);
- 流动性大。

### 3.3 三方结构

```
老板(需求) ←→ 平台(撮合 + 抽成 + 管理) ←→ 陪玩(供给)
                    ↑
                俱乐部(组织陪玩、加盟)
```

**平台的价值,是「撮合」+「管理」;俱乐部的价值,是「组织」+「培训」。**

## 四、场景:五个「开黑时刻」

| 场景 | 时间 | 行为 | 对应产品 |
|---|---|---|---|
| **排位上分** | 晚上、周末 | 找技术陪,冲击段位 | 技术陪玩 |
| **娱乐开黑** | 随时 | 找人一起玩,不看重输赢 | 娱乐陪玩 |
| **深夜孤独** | 23:00-02:00 | 一个人睡不着,找人聊天 | 语音房 |
| **赛事围观** | 比赛日 | 看比赛、打水友赛 | 赛事 |
| **社交扩列** | 周末 | 认识人、找固定队友 | 社区、语音房 |

### 4.1 场景的共性:「一个人」

**东东电竞的所有场景,都指向同一个前提:一个人打游戏,太孤独了。**

- 一个人排位,输了没人安慰;
- 一个人开黑,没人配合;
- 一个人深夜,没人说话。

**它卖的不是「游戏服务」,是「游戏里的陪伴」。**

### 4.2 一个被忽略的场景:「被服务」

在传统游戏里,玩家是「玩家」;在陪玩平台里,玩家是「老板」。

- 陪玩会叫「老板」;
- 陪玩会等你;
- 陪玩会夸你。

**这是一种「角色反转」的体验:在现实里,他可能是个普通打工人;在游戏里,他是「老板」。**

---

## 五、需求:五层,本质是「被服务的感觉」

```
第五层  面子需求    「我点得起贵的陪玩」
   ↑
第四层  社交需求    「有人陪我玩、陪我聊」
   ↑
第三层  情绪需求    「被夸、被重视、被叫老板」
   ↑
第二层  技术需求    「上分、学技术」
   ↑
第一层  娱乐需求    「打发时间」
```

**第一层:娱乐。** 打发时间,是基础。

**第二层:技术。** 上分、学操作,是「功能性需求」。

**第三层:情绪。** 被夸、被重视、被叫「老板」——这是「情绪价值」。

**第四层:社交。** 有人一起玩、一起聊,是「陪伴」。

**第五层:面子。** 点得起贵的陪玩、在排行榜上有名,是「身份」。

**本质一句话:**

> **用户要的不是「一个高手」,是「一个愿意陪我、捧我的人」。**

**这和海底捞的逻辑一模一样:你吃的不是火锅,是「被服务的感觉」。**

## 六、模式:平台、俱乐部、陪玩的三方分成

### 6.1 收入结构

| 来源 | 说明 |
|---|---|
| **订单抽成** | 陪玩接单,平台抽成 |
| **考核费** | 娱乐/技术考核,500 钻石/轮 |
| **俱乐部加盟** | 加盟费、管理费 |
| **赛事/活动** | 赞助、报名费 |

### 6.2 成本结构

| 成本 | 说明 |
|---|---|
| **陪玩分成** | 订单大头给陪玩 |
| **获客** | 买量、赛事赞助 |
| **管理** | 近 300 人运营团队 |
| **合规** | 审核、实名、税务 |

### 6.3 一个「重管理」的模型

**东东电竞的运营团队近 300 人,陪玩超 4,000 名。**

这个比例(1:13)在平台型公司里极高——**它不是「轻平台」,是「重服务」。**

**重服务的好处:体验可控、口碑好;坏处:成本高、扩张慢。**

## 七、争议:野蛮生长的代价

### 7.1 四件事

| 时间 | 事件 |
|---|---|
| 2026.3 | 与 PeRo 陪玩店互撕,涉及「挖打手」「举报偷税」 |
| 2026.4 | 陪玩「ybb 事件」,平台处罚引发舆论 |
| 2026.5 | 2,000 万奖金《三角洲行动》赛事,官宣 24 小时后被官方叫停 |
| 2026.7 | CEO 为「Bug 强制结单」致歉,直播自证被封 |

### 7.2 这些争议说明什么

**第一,陪玩行业,仍在「灰色地带」的边缘。**

- 陪玩、语音、打赏,天然靠近「软色情」「未成年人」的监管红线;
- 平台越规范,越容易被「不规范」的同行拖下水。

**第二,平台与游戏官方的利益冲突。**

- 陪玩平台做大,会「分流」官方赛事的流量和商业价值;
- 东东电竞的 2,000 万赛事被叫停,是「平台 vs 官方」的典型冲突。

**第三,平台与陪玩的权力不对等。**

- 平台掌握规则、罚款、封号权;
- 陪玩是「弱势一方」,容易引发舆论反弹。

### 7.3 但它也有「正面」的一面

- 提供就业:4,000+ 陪玩,近 300 人运营团队;
- 纳税:负责人称「一个月纳税 1,000 万」;
- 规范化:实名、考核、禁止私单、禁止色情。

**它是一个「争议很大,但确实在解决问题」的公司。**

## 八、六个判断

### 判断一:它卖的是「情绪服务」,不是「游戏技术」

- 技术可以练,情绪买不到;
- 陪玩的核心竞争力,是「会说话」「会来事」;
- **「电竞界海底捞」这个称号,比「技术最强」更值钱。**

### 判断二:它的护城河是「管理」,不是「流量」

- 流量可以买;
- 但「4,000 个陪玩的考核、培训、管理」,是重活;
- **重活,才是壁垒。**

### 判断三:陪玩行业的终局,是「正规化」

- 监管趋严,灰色平台会被淘汰;
- 谁能把「陪玩」做成「正规服务」,谁就能活下来;
- **东东电竞的「严」,是在赌这个终局。**

### 判断四:它的最大风险,是「舆论」和「监管」

- 一次事件,可能毁掉多年口碑;
- 陪玩行业的「原罪」,很难彻底洗白;
- **它必须比同行更干净,才能活下去。**

### 判断五:线下是它的「根」,也是它的「锚」

- 从网咖起家,让它懂「服务」;
- 线下门店,是「信任」的载体;
- **纯线上平台,很难建立这种「服务基因」。**

### 判断六:它可能成为「电竞行业的链家」

- 链家做的是「撮合 + 规范 + 服务」;
- 东东电竞做的是「撮合陪玩 + 规范行业 + 服务老板」;
- **如果它能定义「陪玩的标准」,它就不只是一个平台。**
