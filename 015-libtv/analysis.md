# LibTV:把「抽卡」变成「导演」

> 拆解对象:LibTV(哩布哩布 / 演语科技 Evoken)
> 拆解维度:需求 · 场景 · 价值 · 商业模式 · 变革 · 竞争 · 风险
> 一句话:**它卖的不是「视频生成」,是「一段能交付的片子」——把模型的不确定性,封装成导演的确定性。**

---

## 一、它是什么:一个「AI 制片厂」

2026 年 3 月 18 日,哩布哩布(LiblibAI)上线 LibTV。

它不是一个「输入一句话、输出一段视频」的生成器,而是一个**专业视频创作平台**:

- **无限画布 + 节点式工作流**:剧本、分镜、角色、场景、视频、音频,全部在一张画布上流转;
- **人类创作者 + AI Agent 双入口**:你可以自己拉节点,也可以让 Agent 替你跑;
- **模型聚合**:集成可灵 3.0、Seedance 2.5 / 2.5 Flash、Wan 3.0、H3、MAGI-2、HappyHorse 1.0 等主流模型;
- **20+ 独家能力**:角色三视图、主体库(角色一致性)、多机位 9/25 宫格、剧情推演 4 宫格、画面推演(3 秒后 / 5 秒前)、电影级灯光(24 种主光位、9 种轮廓光)、镜头聚焦、9/25 宫格切分。

### 四层结构

```
模型层   可灵 / Seedance / Wan / H3 / MAGI-2 …（别人的模型）
   ↓
工作流   无限画布 + 节点 + 一致性工具（自己的）
   ↓
Skill    100+ 导演经验封装（自己的）
   ↓
Agent    OpenAPI + Skill Hub（自己的）
```

> **模型是租来的,工作流是自建的。** 这是理解 LibTV 的第一把钥匙。

### 公司盘子

- 母公司:演语科技(Evoken),旗下有 LiblibAI、LibTV、星流;
- 2026 年 6 月完成近 **3 亿美元 B+ 轮**,估值超 **20 亿美元**,ARR 破 **3 亿**;
- LiblibAI 累计用户超 **3,000 万**,50 万+ 原创模型,日均生成图片 500 万+;
- 创始人陈冕,90 后,前字节高管。

## 二、需求:五层,本质是「确定性」

普通 AI 视频工具解决的是「生成」;LibTV 解决的是「交付」。

```
确定性 · 这段片子能交片、能过审、能复用
效率   · 一条片子从 7 天到 1 天
一致性 · 20 集不换脸、不换景、不换光
可控   · 镜头、灯光、机位、表演,能调
出片   · 先有一段能看的视频
```

- **出片**:先有画面;
- **可控**:不是抽卡,是「调」出来的;
- **一致性**:角色、场景、光线,跨镜头稳定;
- **效率**:从「一周一条」到「一天几条」;
- **确定性**:能交付、能复用、能规模化。

### 本质一句话

> **「我需要的不是一段视频,是一个能交片的片子。」**

生成是概率,交付是工程。**LibTV 卖的是「把概率变成工程」的能力。**

---

## 三、场景:六种「片子」

| 场景 | 客户 | 过去 | 现在 |
|---|---|---|---|
| 短剧 / 漫剧 | 短剧团队 | 7-15 天/集,演员+场地 | 1-2 天/集,角色可复用 |
| 广告 TVC | 品牌 / 4A | 数十万一条,拍摄+后期 | 几千到几万,当天出片 |
| 电商带货 | 商家 / 达播 | 拍样品、搭场景 | 一张产品图,生成多条素材 |
| 音乐 MV | 音乐人 | 预算高、周期长 | 概念图 → 分镜 → 成片 |
| 自媒体口播 | 博主 / MCN | 写稿、拍摄、剪辑 | 脚本 → 数字人 → 成片 |
| 影视预演 | 剧组 | 手绘分镜、Previz 团队 | 分镜直接生成动态预演 |

### 最典型的场景:短剧

- 一张角色图,**20 集不换脸**;
- 剧情推演 4 宫格、画面推演(3 秒后 / 5 秒前),把「下一镜」变成可计算的;
- 多机位 9/25 宫格,一个场景一次出多角度;
- 片段重拍、AI 智能剪辑、爆款拉片。

> 这就是「AI 短剧工业化」:不是「AI 拍得更好」,是「AI 拍得更快、更稳、更便宜」。

## 四、价值:三笔账

### 1. 成本账

| 项目 | 传统 | AI(LibTV 类) |
|---|---|---|
| 广告 TVC | 数十万 / 条 | 几千-几万 / 条 |
| 短剧 | 数万-数十万 / 集 | 数千 / 集 |
| 素材迭代 | 重拍 = 重花钱 | 改提示词/换节点 |
| 边际成本 | 每拍一次都要钱 | 每生成一次按秒计费 |

TikTok CEO 周受资的说法更直接:**品牌视频广告成本,已从数百上千美元降到 1-10 美元。**

### 2. 周期账

- 传统 TVC:创意 1 周 + 拍摄 1 周 + 后期 2 周;
- AI:创意 1 天 + 生成 1 天 + 精修 2 天。

**周期从「月」变成「周」,从「周」变成「天」。**

### 3. 确定性账

这是最容易被忽略、也最值钱的一笔:

- 角色一致性(主体库 + 三视图);
- 场景一致性(光影、机位、焦段);
- 风格一致性(Skill 封装的「导演判断」)。

> **成本决定「能不能做」,周期决定「来不来得及」,确定性决定「敢不敢交给客户」。**

## 五、商业模式:四层收入

### L1 订阅(月卡 / 年卡)

- 月卡、年卡,配积分;
- 年会员最高赠送 15 个月,双 11 期间 6,699-6,999 元档;
- 19.9 元「3 日高级会员 + 1,200 积分」拉新。

### L2 按秒计费(积分消耗)

- Seedance 2.5:单秒最低约 **0.16 元**;
- Seedance 2.5 Flash:单秒最低约 **0.10 元**;
- MAGI-2:年卡折算每秒最低约 **5 分钱**。

**按秒计费,本质是把「算力成本」转嫁给「使用强度」。**

### L3 企业 / API / Agent

- OpenAPI:生图、生视频、会话管理;
- libtv-skills:面向 Agent 的技能包(遵循 OpenClaw 规范),`npx skills add` 即可接入;
- 企业客户:批量生成、私有素材库、团队协作。

### L4 生态(模型 / 素材 / 课程)

- 模型聚合:多模型接入,按调用分成或加价;
- 模板 / 素材 / 课程:如「LibTV 第一门 AI 视频课」、联名 IP(王者荣耀);
- 社区导流:LiblibAI 的 3,000 万用户,是 LibTV 的天然流量池。

### 单位经济的核心

> **毛利 = 售价(按秒) − 模型成本(按秒) − 算力/带宽。**
> 它的毛利空间,取决于两件事:**能不能拿到更便宜的模型价**,和**能不能用工作流卖出溢价**。

## 六、变革:五件正在发生的事

### 1. 生产关系:导演从「执行者」变成「决策者」

过去,导演的价值在于「调度资源」;现在,资源是算力,导演的价值在于**判断**——选哪个镜头、哪种光、哪版表演。

**一个人,就是一家制片厂。**

### 2. 成本结构:从「人力密集」到「算力密集」

- 传统:演员、场地、器材、后期,都是人;
- AI:模型、算力、订阅,都是「按次付费」。

**固定成本下降,可变成本上升。** 这对小团队是利好,对大公司是「组织重构」。

### 3. 内容供给:从「稀缺」到「过剩」

当一条 TVC 只要 1-10 美元,内容会像工业品一样被生产出来。

但**注意力是稀缺的**:

- 短剧投流:巨量引擎约占 73%,腾讯广告约 17%,快手约 8%;
- 流量成本同比上涨超 100%;
- 千次播放收益,从 2025 年下半年的约 60 元,跌到 15-30 元。

> **AI 解决了「生产」,没有解决「分发」。** 内容工业化之后,瓶颈从「拍不出来」变成「投不出去」。

### 4. Agent 原生:视频成为「可调用的能力」

LibTV 的 Agent 入口,意义不在于「自动化」,而在于:

- 视频生成,第一次成为**Agent 的工具**;
- 「一句话 → 10 集大纲 → 分镜 → 成片」成为一条链;
- 100+ Skill,把「导演经验」变成「可调用的函数」。

**这是「人机协同」的新界面:人给判断,Agent 给产能。**

### 5. 平台竞争:模型商品化,工作流生态化

当所有平台都能调用可灵、Seedance,**模型就不再是壁垒**。

壁垒变成:

- 工作流(节点、一致性、协作);
- Skill(经验封装);
- 生态(素材、模板、社区、Agent)。

## 七、竞争:它和谁抢

| 玩家 | 强在哪 | 短板 |
|---|---|---|
| **即梦(字节)** | 流量、模型、剪映生态 | 更偏「大众创作」,专业工作流弱 |
| **可灵(快手)** | 模型能力强、商业化早 | 工具链偏「生成」,缺制片流程 |
| **海螺(MiniMax)** | 生成质量、创作者口碑 | 生态与工作流仍在补 |
| **Runway / Veo** | 技术前沿、全球市场 | 本土化、价格、生态弱 |
| **LibTV** | 工作流 + Skill + Agent + 社区 | 模型依赖第三方,品牌仍在建立 |

**它的对手不是「某个模型」,是「模型厂商自己做的工具」。**

## 八、风险

| 风险 | 说明 |
|---|---|
| 模型依赖 | 核心模型来自可灵、Seedance 等,议价权在别人手里 |
| 同质化 | 节点式工作流正在成为行业标配 |
| 版权与合规 | 角色一致性、名人肖像、训练数据,都是雷区 |
| 算力成本 | 按秒计费,毛利被算力价格牵着走 |

| 行业内卷 | 短剧投流成本上涨,客户预算收缩 |
| 大厂挤压 | 字节、快手若把工作流免费化,独立平台压力巨大 |

## 九、六个判断

### 1. 它卖的不是「生成」,是「确定性」

生成是概率,交付是工程。**能交片,才值钱。**

### 2. 模型会商品化,工作流不会

当所有平台都能调用同一批模型,壁垒就只剩「怎么用」。

### 3. Agent 入口,是它最被低估的护城河

视频第一次成为 Agent 的工具,而 LibTV 把「导演经验」封装成了可调用的 Skill。

### 4. 「一人制片厂」成立,但「一人发行」不成立

生产端被 AI 抹平,分发端仍然是巨头的战场。**投流,才是短剧真正的门槛。**

### 5. 它的对手,是模型厂商自己的工具

即梦、可灵、海螺,随时可以把工作流做成「免费标配」。

### 6. 终局:要么做「AI 制片厂的操作系统」,要么被吞掉

做成了,它是视频时代的「Adobe」;做不成,它只是模型厂商的一个「分销渠道」。
